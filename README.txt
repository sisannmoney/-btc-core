BTC CORE INTERACTIVE V2
=======================

追加機能
- MARKET: CoinGeckoから7日間のBTC/JPYチャートを取得・描画
- WALLET: 保有BTC + 平均取得単価を保存し、現在評価額・含み損益・損益率を表示
- 中央BTCボタン:
  - タップ = 市場データ即時更新
  - 約0.8秒長押し = CORE AWAKENED / NORMAL 切替
- EXPLORER: mempool.space を開く
- SETTINGS: 自動更新間隔を変更
- 左上MENU / 右上LIVEも操作可能
- PWA / ホーム画面 / 全画面起動対応

注意
- ChatGPT内のHTMLプレビューでは外部API通信が制限される場合があります。
- リアルタイム価格・7日チャート・PWAインストールはHTTPS公開URLでの利用を推奨します。
